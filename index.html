전체 흐름 요약

예시: 온보딩 모바일화 사이트

STEP 1

코딩 단계

  1. Claude AI로 코드 생성
  2. VS Code로 직접 수정
  3. 코드 파일을 Github에 업로드하여 배포
  4. 생성된 링크 복사
STEP 2

사용 단계

  1. 생성된 링크 + 접속코드 공유
  2. 교육생이 온보딩 사이트에서 이름 입력 · 퀴즈 풀기 · 시험 · 설문 제출
  3. 제출한 데이터가 구글 시트에 자동 저장
STEP 3

수집 단계

  1. 담당자가 구글 시트에서 데이터 파일 엑셀 형식으로 다운로드
  2. 엑셀로 가공 진행

QnA

Q1 Claude AI로 생성한 코드를 꼭 직접 수정해야 하나요? 처음부터 끝까지 Claude만 시키면 안 되나요?

A1Claude는 사용할 수 있는 리소스에 제한이 있습니다. 코드 한두 줄을 변경하기 위해 전체 리소스를 사용하기보다는, 직접 수정하는 것이 효율적입니다.

Q2 Github에서도 업로드한 코드를 직접 수정할 수 있던데, 거기서 수정하면 안 되나요? 꼭 VS Code를 켜야 하나요?

A2VS Code에서는 수정한 코드를 미리보기로 즉시 확인할 수 있습니다. 오류를 줄이기 위해 VS Code 사용을 권장합니다.

Q3 교육생이 본인 폰으로 웹사이트에 입력한 이름과 필기 시험 답안, 설문조사 결과를 우리가 어떻게 알 수 있나요?

A3웹사이트에서 [제출]을 누르면 입력한 값들이 교육서비스팀 구글 시트에 자동으로 저장이 됩니다.

Q5 제작한 웹사이트를 보다 쉽게 공유하려면 어떻게 해야 하나요?

A5qr.naver.com 사이트에서 qr 코드로 만들어 배포하면 됩니다.

01

VS Code 사용 가이드

코드 파일을 직접 수정하고, 저장 전 미리보기로 확인합니다

프로그램 설명

VS Code

html, css, js, py 등의 코딩 파일들을 직접 수정하는 프로그램

웹사이트를 이루는 파일 구조

파일명역할수정 대상
*.html 웹사이트의 뼈대 및 내용, 정지 요소 소식지 아티클 내용, 온보딩 시간표 / TEST / 설문 내용 변경 등
*.css 웹사이트의 색상, 폰트 등 디자인 요소 특별한 경우 외에는 수정 불필요
*.js 웹사이트 동작 로직, 입장 코드 / 퀴즈 팝업 등 움직이는 요소 소식지 교육 현황, 온보딩 입장 코드 변경 등

설치 및 기본 사용 가이드

사전 준비 → ㄱ. 설치 → ㄴ. Live Preview 설치 → ㄷ. 폴더 열기 → ㄹ. 코드 수정 → ㅁ. 미리보기 → ㅂ. 저장
사전 준비

*.html 등의 파일을 준비합니다.
기존 작업 파일을 사용하거나, AI를 통해 만든 파일을 다운로드합니다. (Appendix 참고)

ㄱ. 프로그램 다운로드 및 설치

code.visualstudio.com/Download 에서 파일을 다운로드하여 설치 후 실행합니다.

ㄴ. Live Preview 확장 설치
  1. 프로그램 좌측의 확장팩(Extensions) 탭으로 들어가기
  2. "Live Preview" 검색
  3. Microsoft 사에서 만든 Live Preview를 찾아 Install 클릭하여 설치
ㄷ. 코드 파일 폴더 열기
  1. 폴더 내 파일이 전부 불러와집니다. File > Open Folder
  2. html, css, js 코드 파일들이 저장된 폴더를 선택하여 열기
  3. 좌측 [파일 목록]에서 수정할 파일을 클릭하여 [코드 수정창] 확인
ㄹ. 코드 수정하기 접속 코드 변경 예시
  1. app.js 파일에서
  2. // 비밀번호 설정 부분을 찾아
  3. '0601' → '원하는 숫자'로 변경
ㅁ. 수정 사항 미리 보기
  1. index.html 파일로 들어가기
  2. 우측 상단 돋보기 모양의 Live Preview 탭 클릭
  3. 탭 하단에 미리보기 창 확인
ㅂ. 저장

File > Save All 로 전체 수정사항을 저장합니다.

02

Github 사용 가이드

완성된 코드를 업로드하여 누구나 접속 가능한 링크로 발행합니다

프로그램 설명

Github

코딩 파일들을 업로드하여 배포하고, 공유 링크를 생성해주는 사이트

전체 흐름

ㄱ. 접속 및 로그인 → ㄴ. 프로젝트 생성 / 선택 → (ㄷ. 초기 세팅) → ㄹ. 파일 업로드 → (ㅁ. 발행) → ㅂ. 발행 확인

※ ( ) 표시된 ㄷ, ㅁ 과정은 새로운 사이트를 생성할 때만 필요합니다.

ㄱ. 접속 및 로그인
  1. github.com 에서 Sign in > Continue with Google
  2. 교육서비스팀 공용 구글 계정을 선택하여 로그인
ㄴ. 프로젝트 생성 또는 선택
  1. 새 프로젝트 생성 시 : 화면 좌측 상단의 [New] 클릭
  2. 기존 사이트 수정 시 : 수정할 프로젝트 선택
ㄷ. (새 사이트 생성 시) 초기 세팅
  1. 사이트 주소의 / 뒷부분에 해당하는 Repository name을 영문으로 작성
  2. Description에 대략적인 설명 작성 (한글 가능)
  3. Create repository 버튼을 클릭하여 생성 완료
ㄹ. 파일 업로드
ㄹ-1. 새 사이트 생성 시
  1. [Code] 탭 들어가기
  2. [uploading an existing file] 선택
ㄹ-2. 기존 프로젝트에 파일 업로드
  1. [Code] 탭 들어가기
  2. + 선택
  3. [Upload files] 선택
ㄹ-3. 파일 업로드 완료 및 저장
  1. 업로드 창에 파일을 직접 드래그하거나, [choose your files]로 업로드
  2. [Commit changes]로 저장
ㅁ. (새 사이트 생성 시) 발행하기
  1. 최상단 [Settings] 탭 들어가기
  2. 좌측의 [Pages] 탭 들어가기
  3. [Branch] 하단의 [None]을 [Main]으로 변경 후 [Save]
ㅂ. 발행 확인 및 사이트 주소 찾기
  1. 최상단 [Code] 탭 들어가기
  2. 우측 [Deployments] 하단 [github-pages] 클릭
  3. github-pages 하단 주소를 클릭하여 발행 확인
  4. 해당 주소를 공유하면 누구나 웹페이지에 접속할 수 있습니다.
